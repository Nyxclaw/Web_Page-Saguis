# Invitación a Gonda 🐾

Versión estática, mobile-first y compatible con GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `script.js`

## Publicar
1. Crea un repositorio en GitHub.
2. Sube los tres archivos a la raíz.
3. Ve a Settings > Pages.
4. Elige Deploy from a branch.
5. Rama main, carpeta /root.
6. Guarda y espera la URL pública.

## Comportamiento del botón No
- Primer intento: se mueve y el gato interviene.
- Segundo intento: vuelve a moverse.
- Tercer intento: acepta la respuesta y muestra una pantalla respetuosa.
